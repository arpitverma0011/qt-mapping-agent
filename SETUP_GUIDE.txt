# QT Mapping Agent — Setup Guide
# Read this top to bottom. Follow every step in order.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 1 — Install Node.js (one time only)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Go to: https://nodejs.org
2. Click the green button that says "LTS" (e.g. "20.x.x LTS")
3. Download and run the installer. Keep clicking Next/Continue.
4. When done, open Terminal (Mac: Cmd+Space → type "Terminal" → Enter)
   OR Command Prompt (Windows: press Win key → type "cmd" → Enter)
5. Type this and press Enter to confirm Node installed:
   node --version
   You should see something like: v20.11.0

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 2 — Create a GitHub account (one time)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Go to: https://github.com
2. Click "Sign up" — use your email and create a password
3. Verify your email

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 3 — Put the code on your computer
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Unzip the file I gave you (qt-mapping-agent.zip)
   You should see a folder called "qt-mapping-agent"
2. Open Terminal / Command Prompt
3. Navigate into the folder. If it's on your Desktop, type:
   Mac:     cd ~/Desktop/qt-mapping-agent
   Windows: cd C:\Users\YourName\Desktop\qt-mapping-agent
4. Install dependencies (this downloads required packages):
   npm install
   Wait for it to finish — takes about 1-2 minutes.
5. Test it runs locally:
   npm run dev
   Open your browser and go to: http://localhost:3000
   You should see the QT Mapping Agent. Press Ctrl+C to stop.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 4 — Push code to GitHub
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Install Git if you don't have it: https://git-scm.com/downloads
2. In Terminal (inside qt-mapping-agent folder), run these 5 commands one by one:
   git init
   git add .
   git commit -m "QT Mapping Agent v1"
3. Go to https://github.com → click "New repository"
4. Name it: qt-mapping-agent
5. Keep it Public or Private (either works)
6. Click "Create repository"
7. GitHub will show you commands. Run these (replace YOUR_USERNAME):
   git remote add origin https://github.com/YOUR_USERNAME/qt-mapping-agent.git
   git branch -M main
   git push -u origin main

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 5 — Deploy to Vercel (get a live URL)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Go to: https://vercel.com
2. Click "Sign up" → choose "Continue with GitHub"
3. Authorize Vercel to access your GitHub
4. Click "Add New Project"
5. Find "qt-mapping-agent" in the list → click Import
6. Click Deploy (keep all settings as default)
7. Wait ~2 minutes. You'll get a URL like:
   https://qt-mapping-agent-yourname.vercel.app
   ← This is the link you share with anyone!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 6 — Add your Anthropic API key (IMPORTANT)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Your API key must be added to Vercel. This keeps it SECRET — 
no one can see it, not even users of the tool.

1. Go to: https://console.anthropic.com
2. Click "API Keys" in the left menu
3. Click "Create Key" → copy the key (starts with sk-ant-...)
4. Go to your Vercel dashboard: https://vercel.com/dashboard
5. Click your qt-mapping-agent project
6. Click "Settings" → "Environment Variables"
7. Click "Add Variable"
   Name:  ANTHROPIC_API_KEY
   Value: paste your key here (sk-ant-...)
8. Click Save
9. Go to "Deployments" → click the 3 dots → "Redeploy"
10. Wait 1 minute → your live URL now works!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 7 — Share with your friend
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Just send them your Vercel URL:
https://qt-mapping-agent-yourname.vercel.app

They open it in any browser. No login needed.
They upload their file, run the mapping, download the Excel.
They don't need an API key — yours is already configured.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
"node is not recognized" → Restart your terminal after installing Node.js

"npm install fails" → Make sure you're inside the qt-mapping-agent folder
  Check with: ls (Mac) or dir (Windows) — you should see package.json

"ANTHROPIC_API_KEY not configured" → Follow Step 6 again carefully.
  After adding the key, you MUST redeploy from Vercel dashboard.

"Rate limit error" → You've hit the Anthropic API rate limit.
  Wait 60 seconds and try again. Or upgrade your Anthropic plan.

"File won't upload" → Make sure it's .csv, .xlsx, or .xls format.
  Max file size is 10MB.
